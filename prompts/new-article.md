# 글 추가 요청 — 오늘의 이슈

사용자는 아래 중 하나만 말하면 된다:
- **"오늘 AI 이슈 정리해줘"** → 선정 기준으로 이슈를 고르고 리서치부터 작성까지 진행
- **"<토픽>으로 글 써줘"** → 지정된 토픽으로 진행
- **"<토픽> 총정리 써줘"** → 검색형 가이드 작성 (CLAUDE.md '검색형 가이드' 규칙: 빠른 답 → 의도별 섹션 → 표 → FAQ → 기준일·내부 링크)

## 절차

1. **이슈 수집**: WebSearch + 1차 소스(OpenAI/Anthropic/DeepMind 공식 블로그) + 국내 언론(연합뉴스·AI타임스 등). 최근 24~48시간 우선
2. **선정 기준 확인** (CLAUDE.md): 새 사실 / 한국 독자 영향 / 구조적 변화 — 2개 이상 충족 못 하면 다른 이슈로
3. **사실 검증**: 숫자·발표 내용은 원 출처에서 직접 확인. 확인 안 되는 사실은 제외
4. **작성**: `content/posts/<영문-파일명>.md` — CLAUDE.md의 형식·템플릿·팩트 규칙 적용, `draft: true`
5. **검증**: hugo 빌드 에러 없는지 확인 (서버 켜져 있으면 자동 반영)
6. **보고**: 사용자에게 요약 → 검수 승인 후 `draft: false`

## 품질 기준 (미달이면 발행 보류)

- 3줄 요약이 글 전체를 대표하는가
- 핵심 수치가 표로 정리돼 있는가
- 모든 사실에 출처 링크가 있는가
- 5분 안에 읽히는가
