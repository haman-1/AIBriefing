> **2026년 10월 8일 기준** — 9월 8일 첫 정리 이후 달라진 배포 현황·한도·가격을 반영했다. 이후에도 변경이 확인되면 이 글을 업데이트한다.

## 빠른 답

- **지금 쓸 수 있나?** 유료 플랜에는 모두 풀렸다. **Plus는 ChatGPT Work와 Codex에서**, Pro·Business·Enterprise는 채팅에서 **'GPT-6 Pro'** 이름으로 쓴다. 무료 사용자가 10월 8일부터 받는 GPT-6는 경량 모델 '루나'로, 아스트라가 아니다.
- **가격은?** 구독은 Plus 월 $20(약 3만 원)부터, **Pro는 월 $100·$200, 새 최상위 Pro 500이 월 $500**이다. API는 100만 토큰당 **입력 $10·출력 $50**, 캐시 입력은 $1이다.
- **아스트라 프로(Astra Pro)는 따로 돈 내나?** 아니다. 계산량을 더 투입해 어려운 작업을 더 오래 추론하는 상위 구성으로, Pro·Business·Enterprise 구독에 포함된다. Plus는 쓸 수 없다.

## 지금 어디서 쓸 수 있나

OpenAI는 9월 3일 아스트라를 공개하면서 "일부 조직에 우선 배포한 뒤 며칠 안에 전체 확대"라고 밝혔다. 한 달이 지난 지금 배포는 끝났고, 플랜에 따라 **아스트라로 들어가는 입구가 다르다.**

- **Plus** — ChatGPT Work와 Codex에서 일반 아스트라를 쓴다. 채팅 앱의 일반 모델 선택기에는 없다.
- **Pro(월 $100·$200·$500)·Business·Enterprise** — 채팅에서 'GPT-6 Pro' 이름으로 아스트라 프로 구성을 쓴다. Enterprise는 관리자가 켜야 하며 기본값은 꺼져 있다.
- **Free·Go** — 아스트라는 대상이 아니다. 10월 8일부터 경량 모델 GPT-6 루나를 받는다.

출시 당시 배포 안전 시스템 카드는 아스트라를 "지금까지 널리 배포된 모델 중 가장 강력한 모델"로 소개했다. 사이버 역량이 처음으로 'Critical' 등급에 도달한 모델이라 배포 단계를 나눠 푼 배경이었다.

### 10월 들어 달라진 것

- **10월 7일, 모든 사용자로 확대** — 유료 플랜은 GPT-6 Sol, 무료·Go 플랜은 GPT-6 Luna(10월 8일)를 받는다. 웹·모바일 채팅에서 기존 GPT-5.6 Sol·Luna를 대체하며, 대상은 매주 ChatGPT를 쓰는 12억 명 이상이다. 다만 이건 채팅 기본 모델 교체일 뿐, 아스트라 자체가 풀린 것은 아니다. 아스트라의 안전 기술은 GPT-6에 이식됐다.
- **인텔리전트 UI와 속도** — 질문에 따라 차트·버튼·입력 양식 같은 조작 가능한 화면으로 답하는 '인텔리전트 UI'가 같은 날 채팅(웹·모바일)에 들어왔다. 웹 검색이 필요한 질문에서는 첫 응답이 평균 44% 빨라졌다(오픈AI 내부 평가).
- **ChatGPT Work·Codex는 변화 없음** — 이번 조정 대상에서 빠졌다. 두 곳의 모델 구성은 그대로 유지된다.
- **경쟁 구도** — 같은 날 앤트로픽도 새 모델을 공개했다. 연합뉴스는 오픈AI의 '무료 개방'과 앤트로픽의 '가격 인하'가 맞붙는 구도로 정리했다.

## 가격 — 구독과 API

9월 말 DevDay를 기점으로 요금제 이름이 정리됐다. 기존 'Pro 5x'(월 $100)·'Pro 20x'(월 $200)는 **Pro 100·Pro 200**으로 바뀌었고, 월 $500짜리 **Pro 500**이 개인용 최상위로 추가됐다.

**구독(ChatGPT)**:

| 플랜 | 월 요금 | 아스트라 관련 내용 |
|---|---|---|
| Free | 무료 | 없음 — GPT-6 루나 제공 (10월 8일부터) |
| Go | 저가 요금제 | 없음 — GPT-6 루나 제공 (10월 8일부터) |
| Plus | $20 (약 3만 원) | Work·Codex에서 일반 아스트라 |
| Pro 100 | $100 | 채팅 GPT-6 Pro + Work·Codex |
| Pro 200 | $200 (약 29만 원) | 위와 같고 한도가 더 큼 |
| Pro 500 | $500 (약 67만 원) | 위 전부 + 아스트라 울트라패스트 |
| Business | 1인당 월 요금제 | 관리자가 멤버별로 설정 |
| Enterprise | 계약제 | 관리자 활성화 필요 (초기 비활성) |

한도는 플랜·모델별로 5시간 창과 주간 창 두 가지로 관리되며, 남은 양은 설정 → 사용량 화면에서 볼 수 있다. 같은 플랜에서 모델을 바꿔도 한도가 늘지는 않는다 — Pro 100과 Business Standard·Premium에서는 GPT-6 Pro와 GPT-5.6 Sol Pro가 한도를 함께 쓴다. Pro 200은 주간 한도를 다 쓰면 GPT-5.6 Thinking(중간)으로 자동 전환된다.

DevDay를 기점으로 Pro 200의 한도도 조정됐다. GPT-6 Pro 주간 메시지 한도는 100건, Codex·Work를 포함한 사용량은 Plus의 10배로 줄었다(기존 200건·20배). 기존 가입자는 한동안 예전 한도를 유지하고, 차액에 상당하는 일회성 크레딧을 받는다.

**API**:

| 항목 | 가격 |
|---|---|
| 입력 100만 토큰 | $10 |
| 캐시 입력 100만 토큰 | $1 |
| 출력 100만 토큰 | $50 |
| 입력 272K 초과 | 요청 전체를 다시 계산 — 입력 $20·캐시 $2·출력 $75 |
| Fast mode (최대 2배 속도) | 2배 요금 |
| Batch·Flex | 표준의 절반 |
| Zero Data Retention | 지원 |

API 모델명은 `gpt-6-astra`이고 Azure·AWS Bedrock에서도 제공된다. 컨텍스트 창은 105만 토큰, 한 번에 낼 수 있는 출력은 최대 12만 8천 토큰이다. 캐시를 쓰면 같은 프롬프트를 반복할 때 입력 비용이 10분의 1로 줄어든다(캐시 쓰기는 $12.50). 입력이 27만 2천 토큰을 넘으면 요청 전체가 두 배 요금으로 다시 매겨지는 점은 주의해야 한다. 참고로 이전 세대 GPT-5.6 Sol의 가격이 입력 $20·출력 $100이었으니 **아스트라는 정확히 절반**이다.

## 아스트라 프로와 울트라패스트

**아스트라 프로**는 일반 아스트라와 같은 모델에 계산량을 더 얹어 어려운 작업을 더 오래 추론하는 구성이다. 채팅 앱에서는 'GPT-6 Pro'로 표시되고 Pro(월 $100 이상)·Business·Enterprise에 포함된다 — Plus는 Work·Codex의 일반 아스트라까지가 한계다.

**울트라패스트(Ultrafast)** 는 9월 말 DevDay에서 공개된 최상위 속도 등급이다. Codex에서 최대 8배 빠르고 초당 300토큰까지 낸다. 월 $500 Pro 500에만 포함되며, API로도 별도 요금(표준의 약 6배)으로 쓸 수 있다. Plus·Pro 100·Pro 200 가입자는 출시 시점 기준으로 쓸 수 없다.

비용을 아끼려면 아스트라 대신 솔 계열을 쓰는 게 낫다. 10월 7일부터 채팅 기본 모델은 GPT-6 솔(유료)·루나(무료)이고, DevDay에서 공개된 **GPT-6.1 Sol**은 "아스트라에 근접한 지능을 5분의 1 비용으로" 내세워 Work·Codex에서 바로 쓸 수 있다.

## 성능은 얼마나 좋아졌나

주요 벤치마크만 추리면:

| 벤치마크 | GPT-6 Astra | GPT-5.6 Sol |
|---|---|---|
| OSWorld 2.0 (컴퓨터 사용) | **72.6%** | 65.7% |
| Terminal-Bench 4.0 (코딩) | **57.9%** | 37.3% |
| Agents' Last Exam (실무 작업) | **59.3%** | 53.6% |
| ExploitBench (보안) | **100%** | 78.5% |

컴퓨터를 직접 조작하는 작업이 빨라진 게 가장 체감될 부분이다 — 같은 과제를 GPT-5.6 Sol이 약 75분 걸리던 걸 Astra는 약 40분에 끝낸다(약 47% 단축). 발표 내용 전체는 [GPT-6 Astra 공개 — 발표 상세 정리](/posts/openai-gpt-6-astra-launch/)에서 볼 수 있다.

## 자주 묻는 질문

**Q. 무료 사용자도 아스트라를 쓸 수 있나요?**
아니다. 아스트라는 유료 플랜과 API 전용이다. 무료·Go 사용자는 10월 8일부터 GPT-6 계열 경량 모델인 루나를 쓴다. 10월 7일 확대는 채팅 기본 모델 교체로, 아스트라 개방이 아니다.

**Q. Plus인데 채팅 모델 선택기에 아스트라가 안 보여요.**
정상이다. Plus는 아스트라를 ChatGPT Work와 Codex에서만 쓸 수 있다. 채팅에서는 아스트라 프로(GPT-6 Pro 표시)가 Pro(월 $100 이상)·Business·Enterprise 전용이다.

**Q. 한국어도 되나요?**
한국어 사용에 영향을 주는 변경은 발표되지 않았다. 아스트라를 비롯한 GPT-6 계열은 API·앱 모두에서 한국어 프롬프트를 그대로 쓸 수 있다.

**Q. GPT-5.6 Sol/Terra/Luna는 어떻게 되나요?**
채팅의 GPT-5.6 Sol·Luna는 10월 7~8일 GPT-6 Sol·Luna로 대체됐다. 다만 GPT-5.6 Thinking은 Pro 200의 한도 소진 시 자동 전환 대상으로 남아 있다. API 지원 종료 일정은 공개되지 않았다.

**Q. 기업 데이터가 학습에 쓰이나요?**
Zero Data Retention(데이터 보존 없음) 옵션을 지원한다. 엔터프라이즈는 관리자가 켜야 하며 기본값은 꺼져 있다.
