> **2026년 9월 8일 기준** — 프롬프트의 `[ ]` 부분은 자기 시트 구조에 맞게 바꿔 넣는다. 받은 수식은 본 시트에 넣기 전에 임시 시트에서 먼저 확인한다.

## 빠른 답

- **ChatGPT로 엑셀 수식을 만들 수 있나?** 가능하다. 핵심은 **① 열 구조 ② 엑셀 버전 ③ 입출력 예시** 세 가지를 함께 주는 것 — 이것만 갖춰도 "이상한 수식"이 나올 확률이 크게 줄어든다.
- **엑셀에 AI 함수(`=COPILOT()`)가 있던데 그걸 쓰면 안 되나?** 안 된다. Microsoft가 **2026년 9월 14일부로 이 함수를 없앤다**고 공식 발표했다. 새로 쓰지 말 것. 엑셀 안에서 AI의 도움을 받으려면 Copilot 창(리본 메뉴)을 쓴다.
- **한국어 엑셀에서도 그대로 되나?** 된다. 한글 엑셀도 **함수명은 영어 그대로** 쓴다(SUM, VLOOKUP…). ChatGPT가 준 수식을 그대로 붙여넣으면 된다.

## 왜 지금 다시 정리하나

두 가지 이유다.

첫째, 수식 만들기는 ChatGPT 활용 중 체감 효과가 가장 큰 업무 중 하나인데도, "아무렇게나 물어봐서 → 어긋난 수식을 받아서 → '역시 안 되네'로 끝나는" 경우가 많다. 프롬프트에 세 가지만 추가하면 결과가 달라진다.

둘째, 엑셀 안에서 쓰던 AI 함수 `=COPILOT()`이 **2026년 9월 14일부로 사라진다**. "엑셀 AI 수식"으로 검색하면 이 함수를 추천하는 글들이 아직 많은데, 이제 그 글을 따라 하면 안 된다. 이 글에서 폐지 경위와 대안을 다룬다.

## 정확도를 끌어올리는 프롬프트 3요소

| 요소 | 왜 필요한가 | 예시 |
|---|---|---|
| **① 열 구조** | AI는 시트를 볼 수 없다. 알려주지 않으면 A열이 뭔지 **지어낸다** — 이것이 "생뚱맞은 셀 참조"의 원인 | `A열=거래일, B열=거래처, C열=금액, 데이터는 2행부터` |
| **② 엑셀 버전** | XLOOKUP·FILTER 같은 함수는 2021 이상에만 있다. 버전을 안 알려주면 없는 함수를 준다 | `Microsoft 365` / `엑셀 2019` |
| **③ 입출력 예시** | 원하는 결과의 형태를 보여주면 수식과 출력 형식을 함께 맞춘다 | "D2에는 `매출`처럼 구분값이 나와야 함" |

이 세 가지가 프롬프트의 뼈다. 아래 상황별 프롬프트에도 전부 반영돼 있다.

## 상황별 프롬프트 5개

### 1. 기본 — 원하는 계산을 말로 주문하기

```
너는 엑셀 수식 전문가다. 아래 조건에 맞는 수식을 만들어 줘.

[엑셀 버전: 예 — Microsoft 365]
[시트 구조: A열=거래일(날짜), B열=거래처, C열=금액, D열=구분(매출/매입), 데이터는 2행부터]
[원하는 것: 이번 달(2026-09) 매출만 합산해 F1 셀에 표시]

출력 형식: 수식 1개 + 동작 설명 한 줄.
요청대로 안 될 부분이 있으면 대안 수식도 함께 제시.
```

**팁**: "이번 달"처럼 상대 표현은 기준 날짜를 괄호로 못박는다. `TODAY()` 기반으로 만들어 달라고 하면 다음 달에도 그대로 재사용된다.

### 2. 오류난 수식 고치기

```
아래 엑셀 수식이 [#오류: 예 — #NAME?] 오류를 낸다. 원인을 찾아 고쳐 줘.

[수식: =VLOKUP(A2, 상품!A:C, 3, 0)]
[의도: A2의 코드로 상품 시트에서 이름을 찾고 싶다]
[엑셀 버전: 예 — 2019]

출력 형식: ① 잘못된 부분 ② 수정 수식 ③ 같은 실수를 막는 팁 한 줄
```

**팁**: `#NAME?`은 대부분 함수명 오타이고, `#REF!`는 참조가 깨진 것, `#VALUE!`는 형식 불일치다. 오류 코드를 프롬프트에 그대로 넘기면 진단이 빨라진다.

### 3. 남이 만든 수식 해석하기

```
아래 수식을 단계별로 해설해 줘.

[수식: 붙여넣기]
[시트 구조: 각 열이 무엇인지 간단히]

순서: ① 안쪽 함수부터 무엇을 하는지 ② 전체가 최종적으로 계산하는 것 한 문장.
만약 논리적으로 개선할 부분이 보이면 마지막에 따로 제안해 줘.
```

**팁**: 인수 인계받은 파일 정리에 강하다. "개선 제안은 별도로"를 요구하지 않으면 해설과 재작성이 뒤섞여 나온다.

### 4. 구식 수식 최신화 — VLOOKUP → XLOOKUP

```
아래 VLOOKUP 수식을 XLOOKUP으로 바꿔 줘.

[엑셀 버전: Microsoft 365]
[수식: =VLOOKUP(A2, 상품!A:C, 3, FALSE)]

요구사항:
1. 찾는 값이 없으면 IFERROR로 "없음" 표시
2. 바꾼 뒤 좋아진 점 한 줄씩 2개
```

**팁**: XLOOKUP은 2021/Microsoft 365 전용이다. 회사가 2019라면 버전란에 명시해야 한다(2번 프롬프트의 `#NAME?` 사고 방지).

### 5. 조건이 여러 개인 요약 — SUMIFS

```
아래 조건의 합계 수식을 만들어 줘.

[엑셀 버전: 예 — Microsoft 365]
[시트 구조: A열=거래일, B열=거래처, C열=금액, D열=구분(매출/매입)]
[조건: ① D열이 "매출" ② A열 거래일이 2026-09-01~09-30]
[출력 셀: F2]

조건이 하나라도 비어 수식이 깨질 경우를 대비해 IFERROR 처리도 넣어 줘.
동작 설명 한 줄과, 조건을 하나 더 추가하려면 어디를 고치면 되는지도 알려 줘.
```

**팁**: 마지막 문장("조건 추가 방법")이 이 프롬프트의 백미다. 다음 달에 스스로 고칠 수 있게 되는 것이 목표다.

직군별로 특화된 프롬프트는 [회계사가 쓰는 ChatGPT 프롬프트 10개](/posts/chatgpt-prompts-for-accountants/)에서 다룬다. 계정과목 분류·마감 체크리스트 등 엑셀과 만나는 실무 패턴들이다.

## 흔한 실패 4가지 — 증상과 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 존재하지 않는 열·셀을 참조하는 수식이 나온다 | 시트 구조를 안 알려줘서 AI가 구조를 **추측**했다 | 열 구조를 프롬프트에 명시(3요소 ①) |
| 붙여넣었더니 `#NAME?` | 내 버전에 없는 함수(XLOOKUP 등)를 줬거나 함수명 오타 | 버전 명시(3요소 ②). 이미 생겼으면 2번 프롬프트로 진단 |
| 합계가 0이 나온다 | 숫자가 텍스트로 저장돼 있거나 조건 서식(앞뒤 공백 등)이 어긋난다 | "숫자가 텍스트일 수 있다"고 알려주고 진단 요청 |
| 이상하게 긴 수식이 나온다 | 요구를 한 문장에 다 우겨넣었다 | 조건을 번호로 나눠서 요청(5번 프롬프트 형태) |

## 엑셀 내장 AI 함수 `=COPILOT()` — 9월 14일 폐지

**무엇이었나.** Microsoft는 2025년 8월 셀 안에서 자연어로 AI를 부르는 함수를 베타 공개했다. `=COPILOT("Classify this feedback", D4:D18)`처럼 쓰는 방식으로, 데이터가 바뀌면 결과도 자동 재계산되고 LABS.GENERATIVEAI 실험 함수의 후속이었다.

**무슨 일이 생겼나.** Microsoft는 공식 발표문(2026년 8월 14일 업데이트)에 다음과 같이 못박았다: **"2026년 9월 14일부터 엑셀의 =COPILOT 함수는 더 이상 사용할 수 없다"** — 구체적인 철회 사유는 밝히지 않았고, 같은 AI 작업을 Copilot 사이드 창에서 계속 지원한다고 안내했다.

**그래서 어떻게 하나.** 정리하면 이렇다.

| | `=COPILOT()` 함수 | Copilot 창 (대안) |
|---|---|---|
| 형태 | 셀에 직접 쓰는 수식 | 리본 메뉴의 사이드 창 |
| 상태 | **2026-09-14 사용 종료** | 계속 제공 |
| 자연어 수식 작성 | 지원했음 | 지원 — 한 번에 수식 하나·수식 열 하나·범위 하나 단위 |
| 결과물 성격 | AI 출력(재계산 시 재생성) | 일반 수식으로 삽입돼 엑셀이 직접 계산 |
| 이용 조건 | Microsoft 365 Copilot 라이선스·베타 채널 | Copilot 이용 권한 (세부는 공식 문서 참조) |

이미 `=COPILOT()`을 쓴 시트가 있다면 9월 14일 전에 일반 수식 또는 Copilot 창이 만든 수식으로 바꿔 두는 것이 안전하다. 수식 자동완성 도움(Formula Completion — 수식 입력 중 실시간 제안)은 별도로 계속 제공된다.

## ChatGPT vs Copilot vs Gemini — 어떤 걸 쓰나

| | ChatGPT | Copilot (엑셀) | Gemini (구글 시트) |
|---|---|---|---|
| 어디서 | 웹·앱 (엑셀 밖) | 엑셀 안 | 구글 시트 안 |
| 시작 조건 | 무료 계정으로 시작 가능 | Copilot 이용 권한 | 구글 AI Pro 이상 구독 |
| 강점 | 긴 대화로 시행착오·`.xlsx`/`.csv` 파일 업로드 분석 | 파일을 안 나가고 바로 | 구글 생태계 사용자에게 가장 자연스러움 |
| 약점 | 수식 복붙이 수동 | 라이선스 필요 | 엑셀 파일엔 부적합 |

경계는 명확하다 — **엑셀 파일 안의 즉석 작업은 Copilot 창, 복잡하거나 반복 시행착오가 필요한 수식 설계는 ChatGPT**다. ChatGPT는 `.xlsx`·`.csv`를 업로드해 데이터를 직접 보게 할 수도 있다(OpenAI 공식 도움말 기준). 단 이 경우도 열 구조 확인은 여전히 내 몫이다. 모델 자체의 성능·가격 비교는 [GPT-6 아스트라 가격·사용법 총정리](/posts/gpt-6-astra-guide/)와 [Gemini 3.8 Flash 가격·사용법 총정리](/posts/gemini-3-8-flash-guide/)에서 확인할 수 있다.

## 자주 묻는 질문

**Q. 한글 엑셀인데 함수명을 영어로 받으면 안 되는 거 아닌가요?**
아니다. 한글 엑셀도 함수명 자체는 영어 그대로 쓰고, 인수 설명(힌트)만 한국어로 표시된다. ChatGPT가 준 영어 수식을 그대로 붙여넣으면 된다.

**Q. ChatGPT 유료 결제를 해야 하나요?**
아니다. 수식 생성·수정·해설은 무료 플랜으로 충분하다. 사용량이 많아지면 플랜 업그레이드를 고려하되 요금은 공식 페이지에서 확인한다.

**Q. 파일째 올려서 시켜도 되나요?**
된다. ChatGPT의 데이터 분석 기능은 `.xlsx`·`.csv` 등을 지원한다. 단 거래처명·주민번호 같은 식별 정보는 지우고 올린다 — 원칙은 [회계사 프롬프트 글](/posts/chatgpt-prompts-for-accountants/)의 마스킹 규칙과 같다.

**Q. 매크로(VBA)도 만들어 주나요?**
코드 생성은 가능하다. 다만 매크로는 파일·시스템에 영향을 주는 영역이라, 코드를 이해하고 검증한 뒤에만 쓴다. 이 글은 수식 범위로 한정한다.

**Q. `=COPILOT()`을 이미 쓰고 있는데 어떻게 되나요?**
2026년 9월 14일 이후 동작이 보장되지 않는다. 해당 수식을 일반 수식으로 바꾸거나 Copilot 창으로 다시 만들어 두자. 기존 결과값을 값으로 붙여넣어 보존하는 것도 방법이다.
