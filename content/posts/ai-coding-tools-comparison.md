> **2026년 9월 21일 기준** — 요금과 한도는 커서·깃허브·앤트로픽의 공식 요금 페이지와 공식 문서에서 직접 확인한 값이다. 달러 가격은 세금 포함 전이고, 원화는 서울외국환중개 매매기준율(1달러 = 1,376.50원)로 환산한 근사치다.

## 빠른 답

- **무료로 가장 오래 쓸 수 있는 도구는?** 깃허브 코파일럿이다. 무료 플랜으로도 매달 2,000건의 코드 자동완성을 쓸 수 있고, VS Code·JetBrains 같은 기존 에디터에 확장으로 바로 붙는다. 학생이면 인증만 거치면 요금 0원이다.
- **월 2만 원대 예산이면?** 쓰는 방식이 기준이다. 에디터 안의 자동완성·챗 중심이면 코파일럿 프로(월 10달러)가 가장 싸다. AI가 파일을 직접 고치는 에이전트 방식까지 원하면 커서 프로(월 20달러)나 클로드 프로(월 20달러, 클로드 코드 포함)다.
- **터미널 작업·자동화까지 맡기고 싶으면?** 클로드 코드다. 터미널에서 동작하는 에이전트라 코드 수정은 물론 테스트 실행이나 스크립트 작성 같은 일도 명령으로 맡길 수 있다. 클로드 프로 구독부터 포함된다.

## 도구 세 개, 붙는 자리부터 다르다

AI 코딩 도구를 하나로 묶어 말하지만, 세 도구는 동작 방식이 근본적으로 다르다.

- **깃허브 코파일럿** — 기존 에디터에 얹는 확장. VS Code, JetBrains 등에서 자동완성과 챗을 쓰고, 모든 플랜에 CLI와 앱이 함께 딸려 온다. 깃허브 계정으로 시작하면 돼서 진입장벽이 가장 낮다.
- **커서** — VS Code를 베이스로 AI를 처음부터 심어 만든 에디터 자체다. AI 에이전트 '컴포저'와 파일 단위 편집이 하나의 흐름으로 이어진다.
- **클로드 코드** — 터미널에서 동작하는 에이전트. 에디터 안에서 추천을 받는 게 아니라, 명령을 내리면 스스로 파일을 읽고 고쳐 온다. VS Code 확장과 데스크톱 앱도 나와 있다.

형태가 다르니 요금 구조도 제각각이다. 도구별로 쪼개서 본다.

## 한눈에 보는 비교

| 구분 | 깃허브 코파일럿 | 커서 | 클로드 코드 |
|---|---|---|---|
| 형태 | 에디터 확장 + CLI·앱 | AI 내장 독립 에디터 | 터미널 에이전트 (+VS Code 확장·데스크톱 앱) |
| 무료 플랜 | 있음 — 월 2,000건 자동완성 | 있음 — 제한적 에이전트 요청 | 없음 — 유료 구독부터 |
| 대표 유료 가격 | 프로 월 10달러 | 프로 월 20달러 | 클로드 프로 월 20달러 (연간 결제 월 17달러) |
| 상위 플랜 | 프로+ 39달러 · 맥스 100달러 | 프로+ 60달러 · 울트라 200달러 | 맥스 100달러부터 |
| 과금 방식 | 월간 크레딧 | 포함 사용량 + 초과분 종량 | 구독 사용량 한도 + 초과분 옵션 |

## 깃허브 코파일럿 — 무료가 가장 넉넉하고, 학생은 0원

공식 플랜 문서 기준 요금은 다음과 같다.

| 플랜 | 가격 | 대표 조건 |
|---|---|---|
| Free | 0달러 | 월 2,000건 자동완성, 제한적 크레딧, 자동 모델 선택만 |
| Student | 0달러 (학생 인증) | 프로급 기능, 일부 프리미엄 모델·서드파티 에이전트 제외 |
| Pro | 월 10달러 (약 1만 4천 원) | 월 1,500 크레딧 (기본 1,000 + Flex 500) |
| Pro+ | 월 39달러 (약 5만 4천 원) | 월 7,000 크레딧, 프리미엄 모델 포함 |
| Max | 월 100달러 (약 13만 8천 원) | 월 20,000 크레딧, 프리미엄 모델 우선 접근 |
| Business | 시트당 월 19달러 | 시트당 월 1,900 크레딧, 중앙 관리 |
| Enterprise | 시트당 월 39달러 | 시트당 월 3,900 크레딧, 깃허브 엔터프라이즈 클라우드 필요 |

짚을 부분 두 가지다. 첫째, 무료 플랜의 2,000건은 자동완성 기준이라 부담 없이 써볼 수 있지만, 챗을 통한 본격 작업은 크레딧 제한에 걸린다. 둘째, 프로(10달러)는 클로드 오퍼스 5나 GPT-6 아스트라 같은 일부 프리미엄 모델이 빠지고, 프로+(39달러)부터 전체 모델이 열린다. 모델 선택이 중요한 사람은 프로부터가 아니라 프로+부터 보는 게 맞다.

학생 인증을 거치면 Student 플랜으로 요금 0원에 프로급 기능을 쓸 수 있고, 교사나 인기 오픈소스 메인테이너도 무료 대상이 될 수 있다.

## 커서 — 에디터째 AI, 대신 무료는 '제한적'

커서의 개인 플랜은 네 단계로 단순하다.

| 플랜 | 월간 가격 | 조건 |
|---|---|---|
| Hobby | 0달러 | 제한적 에이전트 요청, 컴포저 사용, 카드 등록 불필요 |
| Pro | 20달러 (약 2만 8천 원) | 에이전트 한도 확장, 프론티어 모델 접근, MCP·스킬·훅, 클라우드 에이전트 |
| Pro+ | 60달러 (약 8만 3천 원) | 프로 대비 3배 한도 |
| Ultra | 200달러 (약 27만 5천 원) | 프로 대비 20배 한도, 신기능 우선 접근 |

연간 결제로 바꾸면 20% 할인이다. 주의할 점은 과금 구조다. 모든 플랜에 일정량의 사용량이 포함되고, 그걸 넘긴 만큼은 온디맨드 요금이 뒤에 청구된다. 플랜 요금만 보고 예산을 잡으면 실제 청구액이 커질 수 있으니, 자주 쓴다면 사용량 대시보드를 습관적으로 보는 게 좋다.

무료 Hobby의 "제한적 에이전트 요청"이 정확히 몇 건인지는 공식 요금 페이지에 숫자로 공개되지 않았다. 가볍게 맛보는 용도라고 생각하는 게 맞다.

## 클로드 코드 — 구독에 포함, 한도는 채팅과 '공유'

클로드 코드는 따로 파는 상품이 아니라 클로드 구독에 들어 있다.

| 플랜 | 가격 | 클로드 코드 조건 |
|---|---|---|
| 프로 | 월 20달러 (연간 결제 시 월 17달러 환산, 연 200달러 선불) | 포함 — 채팅 등 나머지 기능과 같은 사용량 풀 |
| 맥스 | 월 100달러부터 | 포함 — 프로 대비 5배 또는 20배 사용량 선택 |
| 팀 스탠다드 | 시트당 월 25달러 (연간 20달러) | 포함 |
| 팀 프리미엄 | 시트당 월 125달러 (연간 100달러) | 포함 — 스탠다드 대비 5배 사용량 |
| 엔터프라이즈 | 시트당 월 20달러 (연간) + 사용량은 API 요율 | 포함 |

두 가지 구조를 알아두면 헷갈리지 않는다. 첫째, 사용량이 5시간 단위 롤링 윈도와 주간 한도로 관리되고, 클로드 코드를 돌리면 채팅과 같은 풀에서 차감된다. 코딩 세션 하나가 일상적 채팅 하루치보다 토큰을 많이 쓰기 때문에, 클로드 코드를 쓸 거면 한도 여유가 있는 플랜을 고르는 게 합리적이다. 둘째, 한도가 부족하면 '사용량 크레딧'을 켜서 추가 사용분만 과금하는 방식으로 넘어갈 수 있다.

기업이 API 종량제로 굴릴 때의 참고치도 공식 문서에 나와 있다. 엔터프라이즈 배포 평균이 개발자당 활동일 기준 약 13달러, 월 150~250달러이고 90%는 하루 30달러 미만이다. 개인이 구독 없이 API로만 쓰면 이 감각으로 예산을 잡으면 된다.

## 무료 한도만 따로 보면

| 도구 | 무료 조건 | 비고 |
|---|---|---|
| 코파일럿 | 월 2,000건 자동완성 + 제한적 크레딧 | 자동 모델 선택만, 클라우드 에이전트 제외 |
| 커서 | 제한적 에이전트 요청 + 컴포저 | 카드 등록 없이 시작 |
| 클로드 코드 | 없음 | 클로드 프로(월 20달러)부터 |

무료 체험만 놓고 보면 코파일럿이 압도적이다. 학생이라면 선택의 여지가 없다.

## 무엇을 고를까 — 용도별 기준

- **지금 쓰는 에디터를 바꾸기 싫고, 자동완성 보조가 목적이면** — 코파일럿. 무료로 시작해서 아쉬워지면 프로(10달러)로 올라가는 길이 가장 부답 없다.
- **에디터 환경 자체를 AI 중심으로 다시 세팅하고 싶으면** — 커서. 확장 조합이 아니라 처음부터 AI로 설계된 흐름을 쓴다.
- **여러 파일을 고치고 테스트까지 돌리는 에이전트 작업이 많으면** — 클로드 코드. 터미널에 익숙한 개발자일수록 체감 차이가 크다.
- **학생이면** — 코파일럿 Student. 인증 한 번으로 0원이다.

## 시작하는 법

- **코파일럿**: VS Code(또는 JetBrains) 확장 목록에서 GitHub Copilot을 설치하고 깃허브 계정으로 로그인하면 끝이다. 무료 플랜은 결제 수단 등록이 필요 없다.
- **커서**: cursor.com에서 설치 파일을 내려받아 설치한다. 무료 Hobby로 시작할 수 있다.
- **클로드 코드**: 공식 문서 기준으로 윈도 파워셸에서 `irm https://claude.ai/install.ps1 | iex`, macOS·리눅스는 `curl -fsSL https://claude.ai/install.sh | bash`다. 설치 후 프로젝트 폴더의 터미널에서 `claude`를 입력하면 브라우저 로그인으로 시작한다. npm(Node 22 이상)이나 winget 설치도 공식 지원한다.

## FAQ

**코파일럿 무료 2,000건이면 어느 정도인가요?**
자동완성 제안 2,000건을 한 달간 받을 수 있다는 뜻이다. 코드 보조를 가끔 쓰는 수준이면 충분하고, 챗으로 기능 구현을 붙잡는 방식이면 무료 크레딧에 먼저 닿는다. 무료는 모델 선택도 자동만 가능하다.

**커서 무료(Hobby)로 계속 쓸 수 있나요?**
카드 등록 없이 쓸 수 있고 컴포저와 제한적 에이전트 요청이 제공된다. 다만 한도 수치는 공식 페이지에 공개돼 있지 않아, 매일 쓰는 수준이라면 프로(20달러)를 상정하는 게 마음이 편하다.

**클로드 코드만 따로 결제할 수 없나요?**
없다. 클로드 프로·맥스·팀·엔터프라이즈 구독에 포함되며 무료 플랜은 제외다. 개발자 콘솔에서 토큰 종량(API)으로 쓰는 길은 있고, 구독자도 한도가 부족하면 사용량 크레딧으로 추가 사용분만 결제할 수 있다.

**학생 할인은 어느 도구에 있나요?**
코파일럿뿐이다. 학생 인증 시 Student 플랜(0원)이 열리고, 교사·인기 오픈소스 메인테이너도 무료 대상이 될 수 있다. 이 글 작성 시점의 커서·클로드 공식 요금 페이지에는 별도 학생 플랜이 확인되지 않았다.

**세 도구를 같이 쓸 수도 있나요?**
세 도구는 서로 다른 프로그램이라 함께 설치해 쓸 수 있다. 다만 유료 구독이 늘어나는 만큼 비용이 겹치니, 하나를 메인으로 정하고 나머지는 무료 범위에서 보조로 쓰는 게 유리하다.
